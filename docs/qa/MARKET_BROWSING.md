# Market browsing — October 8, 2026

Tanya requested related Market items together so users do not scroll through
interleaved unrelated products. This is an authorized presentation change.

- Browse by type provides direct access to All treasures, Outfits, Gear,
  Familiars, Effects, Hearth, Seasonal (when available) and Collections.
- Results group related items under headings and counts, ordered by price then
  name and ID within each section.
- Hearth subgroups: settings, rugs/floor decor, wall art, furniture/decor.
  Placement metadata is authoritative; legacy known placement choices apply only
  when no profile/placement metadata exists. Unknown profiles safely fall into
  furniture/decor. No new per-slug taxonomy or inventory behavior is introduced.
- Search, affordability, ownership, class, rarity and collection filters remain.
  An active Seasonal selection remains valid when refreshed data removes the
  final seasonal product, allowing the existing reset action.
- Bundle the pinned Roboto Bold font (google_fonts 6.3.3, SHA-256
  `05b2d0935046846efe2c8786ad1c5d909a11c3431787eea52f2fc70f2a8a6edf`,
  82,928 bytes) for offline filter/menu rendering. Its Apache 2.0 terms match
  the existing Roboto-Medium-LICENSE.txt.
- No schema, pricing, rewards, ownership, availability or equipment changes.
